# Alemneh Enawgaw — Portfolio

A modern, responsive portfolio built with **React**, **TypeScript**, and **Vite**.

## Development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The app is a static Vite site and can be deployed to GitHub Pages, Netlify, Vercel, or any static host. The contact form intentionally opens a direct email workflow rather than exposing third-party email service credentials in the browser.

## Project structure

- `src/App.tsx` — portfolio sections, typed content, theme state, project filtering, and contact form behavior.
- `src/styles.css` — responsive visual system, light/dark themes, accessible motion preferences, and layout.
- `public` assets — profile image, resume, and existing portfolio media.
